# BugAwake Top Profile Timeline Design

## Goal

让首页从左侧独立资料栏改为自然、紧凑的个人博客阅读流，同时为技术、学习、生活建立各一篇可继续扩展的欢迎文章。

## Layout

- 首页保持 Hope 的现有导航、搜索、GitHub 和主题切换。
- 将资料信息移到文章区顶部：圆形头像、`BugAwake`、作者名、简介和 GitHub 链接组成一行简介区。
- 简介下方使用宽度约 820px 的单列文章时间线；不再有固定左栏，也不保留大面积空白。
- 标题、分类和日期使用细分隔线组织；移除首页中的“更多文章会在这里慢慢积累”空状态文案，因为首页将有四篇真实文章。
- 移动端保持相同的阅读顺序，头像和文字自然换行，不出现横向滚动。

## Content

首页按日期显示四篇真实 Markdown 文章：

1. `从零搭建 VuePress 博客`（随笔，现有文章）
2. `欢迎来到技术笔记`（技术）
3. `欢迎来到学习记录`（学习）
4. `欢迎来到生活随笔`（生活）

三篇新增文章各有独立 Markdown 文件、中文 frontmatter、分类、标签、作者、日期和少量可编辑的正文。首页只链接真实页面，不使用草稿或模拟文章。

## Navigation and Categories

- 首页分类筛选链接保留“全部、技术、学习、生活、随笔”。
- 顶部“博文”下拉菜单仍可进入全部文章和分类页。
- 文章目录侧栏更新为四篇文章，保证各欢迎文章都有可见入口。
- 分类页使用对应文章链接，不再全部跳转到文章首页。

## Style

- 保留现有纸张式浅色与深色配色、中文衬线标题和无衬线正文。
- 收紧首页纵向留白与分隔线数量，避免强烈产品页感。
- 资料区不是卡片，不添加阴影、统计数字、装饰标签或新的角色素材。

## Verification

- `pnpm docs:build` 必须成功并渲染新增文章。
- 静态首页必须含四篇文章链接、正确头像路径与现有搜索/主题切换控件。
- 检查新增分类页链接指向对应文章，且移动端布局无横向溢出。
