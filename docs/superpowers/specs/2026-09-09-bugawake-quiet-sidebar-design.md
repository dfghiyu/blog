# BugAwake 安静个人博客改版设计

## 目标

把当前首页从“展示型档案卡片”改成更自然的个人博客：文章是主角，右侧只承担身份和导航作用；桌面端右栏固定，左栏独立滚动；移动端恢复自然的单列阅读流。

## 视觉决定

- 保留深色背景，但降低对比度和装饰密度，使用深灰、暖白和单一薄荷绿作为强调色。
- 删除 `PERSONAL ARCHIVE`、`LATEST NOTES`、`PROFILE / BUGAWAKE`、`NOW` 等英文包装文案。
- 删除首页大标题、文章编号、统计数字、状态章和悬浮式装饰；不再用“像产品页面”的语言包装个人内容。
- 头像缩小为固定资料栏中的自然头像，不覆盖整块资料卡。
- 页面文案只保留用户真实需要理解的内容：BugAwake、个人简介、文章标题、分类、日期、GitHub 和关于页面。

## 页面结构

桌面端使用固定的两列视口布局：

```text
┌──────────────────────────────────────────────┐
│ BugAwake                  首页 文章 关于 搜索 │
├───────────────────────────────┬──────────────┤
│ 左侧文章滚动区                 │ 右侧固定资料 │
│ 文章列表                       │ 头像         │
│ 文章列表                       │ 简介         │
│ 文章列表                       │ GitHub/关于  │
└───────────────────────────────┴──────────────┘
```

- `.blog-home` 占满导航栏以下的视口高度。
- `.article-column` 使用 `overflow-y: auto`，滚动条只属于左侧文章列。
- `.profile-rail` 使用 `position: fixed`，桌面端固定在右侧；资料栏不参与左列滚动。
- 小于 900px 时取消固定布局，资料栏回到文章上方或下方，避免手机端内容被遮挡。

## 内容与交互

- 首页文章保留一篇真实文章和两个“筹备中”占位，但不再用编号强调顺序。
- 分类下拉保留，改成普通中文“筛选文章”。
- 文章 hover 只改变文字颜色和底线，不改变内边距，避免页面跳动。
- 保留搜索、深色模式、GitHub 链接、响应式布局和 `/blog/` base。

## 验收标准

- 桌面端滚动左侧文章时，右侧资料栏位置不变。
- 页面中不出现 `PERSONAL ARCHIVE`、`LATEST NOTES`、`PROFILE / BUGAWAKE`、`NOW /` 等装饰性英文标签。
- 首页不再显示文章编号和统计卡片。
- `pnpm docs:build` 成功，生成首页包含文章列表和头像路径 `/blog/avatar.webp`。
