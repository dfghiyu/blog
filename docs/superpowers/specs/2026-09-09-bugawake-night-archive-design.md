# BugAwake「夜间档案馆」博客改版设计

## 目标

将当前博客从“带有装饰性首页的 VuePress 站点”改成一个适合长期写作和阅读的个人博客。视觉方向为安静、克制的深色二次元科技感，以用户提供的银灰发角色图片作为视觉锚点，站点名称保持为 `BugAwake`。

本次改版只调整视觉、页面结构和展示内容，不迁移技术栈：继续使用 VuePress 2、vuepress-theme-hope、pnpm、Node.js 22 和现有 GitHub Pages 工作流。

## 参考与取舍

参考 VuePress 官方生态中的 Gungnir、Plume、Reco 等博客主题，借鉴它们对文章列表、分类、标签和导航的重视；参考 Astro Minimal 的克制排版、深色/浅色切换和文章优先结构；参考 Shirone 的个人档案、二次元兴趣和资料卡组织方式。

参考只用于提炼信息架构和交互习惯，不复制其源码、素材、角色形象或具体页面布局。

## 视觉系统

- 背景：`#17181D` 夜色黑，内容区域使用 `#202127` 和 `#25262D` 两级表面色。
- 主文字：`#EDF0F4`；辅助文字：`#9BA0AC`；弱化文字：`#707580`。
- 强调色：来自头像图片的浅青 `#8FD6D0`、银蓝 `#9CB5D1`，少量淡粉 `#EAB9C1` 用于状态点或细节。
- 字体：中文正文使用系统无衬线字体，数据、日期和小标签使用等宽字体，避免整页都像宣传海报。
- 形状：小圆角、细边框、低强度阴影；取消大面积渐变、巨大圆角和无内容的留白。
- 记忆点：右侧个人档案卡中的窄幅人物头像，以及贯穿首页的“档案编号 / 时间 / 分类”信息语言。

## 页面结构

### 首页

首页采用两栏布局：

```text
┌─────────────────────────────────────────────────────────┐
│ BugAwake       首页   博文⌄   关于       GitHub  搜索  ◐ │
├───────────────────────────────────────┬─────────────────┤
│ BUGAWAKE / NOTES                      │ PROFILE         │
│ 博文                                  │ 方形人物头像     │
│ 把解决问题的过程写成可回看的记录。     │ BugAwake         │
│                                       │ 简介 / GitHub    │
│ 01  从零搭建 VuePress 博客             ├─────────────────┤
│     日期 · 阅读时间 · 分类             │ 小站数据         │
│                                       ├─────────────────┤
│ 02  下一篇记录                         │ 标签 / 最近关注  │
│ 03  ...                                │                 │
└───────────────────────────────────────┴─────────────────┘
```

- 左栏是主要内容：文章标题、摘要、作者、日期、阅读时间、分类。
- 右栏是稳定的个人信息：头像、站点简介、GitHub、文章/分类/标签统计和标签云。
- 首页不再出现巨大的宣传式主标题；站点的第一任务是让访客找到文章。
- 移动端变为单栏，文章列表在前，资料卡在后。

### 文章、分类、标签、关于

- 统一使用深色背景、浅色正文、浅青链接和银蓝标题。
- 文章页保留主题提供的目录、搜索、代码高亮、面包屑和深色模式。
- 文章列表页采用与首页一致的列表密度，不再出现大片空白。
- 分类和标签页显示真实的当前内容，不虚构文章数量。
- 关于页使用简短个人介绍和技术栈说明，站点名使用 `BugAwake`，作者仍可写作“韩子阳，网名 BugAwake”。

## 头像处理

用户提供了一张 500×1111 的竖版 WebP 图片。使用图片编辑工具生成项目内的正方形头像资源：

- 保留原图人物、发色、表情和画风。
- 以脸部和肩部为主体，裁掉过多的下半身和无关背景。
- 轻微提高对比度和清晰度，保证在 48px 导航头像和 132px 资料卡中都能辨认。
- 不添加文字、Logo、水印、额外人物或新的角色元素。
- 输出到 `docs/.vuepress/public/avatar.webp`，用作导航栏和个人资料卡头像。

## 文件与实现边界

- 重做 `docs/.vuepress/components/HomePage.vue`，使首页结构围绕文章流和个人档案展开。
- 重做 `docs/.vuepress/styles/index.scss`，建立新的颜色令牌、响应式布局和全站文章页样式。
- 调整 `docs/.vuepress/config.ts` 的站点标题、导航、Logo 和主题模式，但保留 `/blog/` base、GitHub 仓库链接和搜索能力。
- 更新 `docs/about/README.md`、`docs/README.md` 和项目 `README.md` 中的站点名称和文案。
- 新增头像资源，不修改 GitHub Actions 的部署机制。

## 验收标准

1. 首页第一屏能看到文章入口、BugAwake 身份和头像，不再是巨大空白或营销式 Hero。
2. 桌面端两栏清晰，移动端单栏可读，导航和搜索仍可用。
3. 深色模式下正文、链接、代码块和侧栏文字有足够对比度。
4. 头像在导航栏、个人卡片和不同屏幕尺寸下不变形、不裁掉脸部主体。
5. `pnpm docs:build` 成功，输出仍部署到 `https://dfghiyu.github.io/blog/`。
6. 不复制参考项目的源码、图片、角色或商标元素。
