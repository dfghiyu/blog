# C++ 学习 Day 3 设计：数组、字符串、指针与引用

## 背景

Day 2 已经介绍了函数、参数、返回值和作用域。Day 3 继续进入基础数据组织，重点解决“如何保存一组数据”“如何处理文本”以及“变量在内存中的地址如何被访问”这三个问题。

文章需要服务于两类场景：

- 初学者能够通过小例子理解数组、字符串、指针和引用；
- 后续准备学习算法的读者能够知道为什么实际刷题通常优先使用 `std::string`、`std::array` 和 `std::vector`，而不是依赖 GCC 专属的 `bits/stdc++.h`。

## 目标

新增一篇正式 C++ 学习文章 `cpp-day-3.md`，并接入现有 C++ 专题导航。文章完成后，读者应能够：

- 声明、初始化和遍历 C 风格数组；
- 识别数组下标越界风险；
- 使用 `std::string` 保存和处理文本；
- 区分 `std::array` 与 `std::vector` 的使用场景；
- 理解变量、地址、指针和解引用之间的关系；
- 区分指针和引用；
- 在函数中安全地传递数组、字符串和容器；
- 使用 Day 3 知识完成数组统计练习。

## 内容设计

### 1. 数组基础

从固定长度的 `int scores[5]` 开始，讲解声明、初始化、下标从 0 开始、`for` 遍历和越界。明确说明 C 风格数组不会自动检查边界。

### 2. 字符串

先说明 C 风格字符数组的结束标记，再以 `std::string` 作为日常开发和算法题的主线，覆盖长度、拼接、下标、遍历和输入差异。

### 3. `std::array` 与 `std::vector`

通过表格对比固定长度与动态长度。使用标准头文件 `<array>` 和 `<vector>`，避免把 `bits/stdc++.h` 当作跨平台方案。示例覆盖 `size()`、`push_back()`、遍历和空容器判断。

### 4. 指针

使用 `int value = 42`、`int* pointer = &value` 和 `*pointer` 建立地址与解引用的关系。介绍空指针 `nullptr`，强调解引用前必须保证指针指向有效对象。

### 5. 指针与引用

用对照示例解释：

- 指针可以为空，也可以改为指向另一个对象；
- 引用必须在初始化时绑定对象，之后不能改绑；
- 函数参数中，引用通常用于表达“必须存在的对象”，指针通常用于表达“可能没有对象”或需要显式处理地址。

### 6. 函数与容器

将 Day 2 的函数知识延伸到 `const std::vector<int>&`、`std::string&` 和返回值，展示只读传递、修改传递和避免不必要复制的基本写法。

### 7. 综合示例与练习

综合示例使用一组学习成绩，完成最大值、最小值、总和和平均值统计。练习包括数组反转、字符串统计、`vector` 去除负数和安全交换，最后提供完成检查表与 Day 4 预告。
