# BugAwake 内容优先博客改版设计

## 参考与边界

信息结构借鉴 [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) 的成熟技术博客思路：身份信息固定在窄栏，文章是页面中心，搜索、分类、标签与文章目录都有明确职责。只借鉴布局和交互原则，不复制其源码、样式或素材；继续使用现有 VuePress 2、vuepress-theme-hope 与 GitHub Pages 工作流。

## 设计目标

BugAwake 是一个中文个人博客，读者主要任务是找到文章并舒适阅读。首页不做个人作品集，不放虚构文章、统计数字、英文装饰、悬浮角色或大型卡片；内容少时也保持克制，不用留白和假数据硬撑版面。

## 布局

桌面端：

```text
┌─────────────────────────────────────────────────────────────┐
│ 顶部：BugAwake / 首页 / 文章 / 关于 / GitHub / 搜索 / 主题    │
├───────────────┬─────────────────────────────────────────────┤
│ 固定左侧栏     │ 中央文章区                                  │
│ 头像 + 名称    │ 最近文章                                    │
│ 简短介绍       │ 分类筛选                                    │
│ 分类 / 标签    │ 真实文章列表                                │
│ GitHub         │ 空状态：暂无更多文章                        │
└───────────────┴─────────────────────────────────────────────┘
```

- 左栏宽度约 250px，桌面端 `position: sticky`，只承载真实身份与导航信息。
- 主内容宽度 760px 左右，不再使用右侧大栏，也不让页面被一篇文章拉得过宽。
- 文章详情沿用主题已启用的目录、阅读时长、标签和代码高亮；桌面端目录位于主题内容侧而非首页。
- 小于 900px 时左栏回到普通文档流，页面成为单列，导航和搜索继续可用。

## 视觉系统

- 默认浅色：纸张 `#F7F5F0`、表层 `#FFFDF9`、正文 `#2B2C2A`、次级文字 `#706F6A`、分隔线 `#E1DDD5`、青绿强调 `#3F766D`。
- 深色模式：夜墨 `#1C1E1D`、表层 `#252826`、正文 `#E9E6DE`、次级文字 `#A6A49E`、分隔线 `#3B3E3B`、青绿强调 `#82BFB3`。
- 标题使用系统宋体优先级（`Songti SC`/`STSong`/serif），正文使用系统无衬线；不下载外部字体，不引入广告式大字或渐变。
- 左栏和文章列表只使用细分隔线，无投影、无玻璃效果、无统计卡片。链接和当前导航使用青绿，但不把强调色铺满页面。

## 内容与功能

- 首页只展示真实已发布文章；未发布文章不作为“筹备中”内容渲染。
- 首页提供全部文章、分类和标签入口；顶部保留搜索、GitHub 链接和深浅色切换。
- 文章页保留现有 VuePress Hope 的目录、日期、分类、标签、阅读时长、代码块与编辑链接。

## 验收

- 首页不存在虚构文章、英文装饰标签、编号、统计卡片或右侧大资料栏。
- 桌面端左侧资料栏可固定，中央文章区保持可读宽度。
- 小屏幕为正常单列流，无遮挡与横向滚动。
- `pnpm docs:build` 成功；搜索、主题切换、GitHub 链接、分类、标签与文章目录配置仍存在。
