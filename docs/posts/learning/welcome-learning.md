# 欢迎来到学习记录

这里放学习中的疑问、资料和阶段性总结。它不追求把每件事都写成标准答案，而是把理解逐渐发生的过程保留下来。

## 从问题开始

学到一半时出现的疑问，往往比整理好的结论更具体。先记下“我现在不明白什么”，再去找资料、做练习，学习才不会只停留在收藏链接。

## 把过程留下来

我会把看过的资料、做过的尝试和仍然模糊的地方放在一起。这样回头看时，不只能看到学会了什么，也能看到自己是怎样走到这里的。

## 慢慢形成自己的方法

隔一段时间回看旧笔记，可以发现哪些知识已经连起来，哪些地方还需要重新练习。学习没有固定的进度，能逐渐找到适合自己的节奏和方法，就值得继续。
