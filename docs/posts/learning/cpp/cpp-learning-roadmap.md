# C++ 学习路线：从能编译到能完成项目

C++ 的学习内容很多：语法、内存、面向对象、标准库、模板、并发、工程化和算法都可能成为一个单独的方向。如果一开始只按目录背知识点，很容易在“学过很多名词”和“能够独立完成程序”之间留下空白。

这条路线的目标不是一次学完所有 C++ 特性，而是让每个阶段都有看得见的产出：能编译、能解释、能修改、能调试，最后能把多个源文件和第三方库组织成一个可以维护的项目。

## 1. 推荐顺序

建议先完成[环境配置文章](/posts/learning/cpp/cpp-environment-setup.html)，再按下面的顺序推进：

| 阶段 | 重点 | 结果 |
| --- | --- | --- |
| 0 | 编译器、VS Code、终端和调试 | 能独立编译并运行一个程序 |
| 1 | 基础语法和控制流程 | 能完成输入、判断、循环题 |
| 2 | 函数和作用域 | 能拆分逻辑并控制变量可见范围 |
| 3 | 数组、字符串、指针和引用 | 能理解连续内存与对象传递 |
| 4 | 类和面向对象 | 能设计小型对象模型 |
| 5 | STL | 能用标准容器和算法解决常见问题 |
| 6 | 模板和现代 C++ | 能写出安全、可读、可复用的代码 |
| 7 | 文件、异常和资源管理 | 能编写有输入输出和错误处理的程序 |
| 8 | 工程化和 CMake | 能维护多文件项目 |
| 9 | 算法与刷题 | 能分析复杂度并稳定训练 |
| 10 | 项目实践 | 能把知识连接成完整作品 |

下面每个阶段都包含学习目标、核心内容、练习产出和完成标准。不要只看完文字就进入下一阶段，至少完成一个小程序或一组练习。

## 2. 阶段 0：环境和编译运行

### 学习目标

理解编辑器、编译器、调试器和构建系统的区别，能在终端和 VS Code 中完成一次从源代码到可执行文件的完整流程。

### 核心内容

- Windows 的 MSYS2 UCRT64、MinGW-w64、GCC 和 GDB；
- macOS 的 Apple Clang、clang++ 和 libc++；
- g++ -std=c++17 main.cpp -o main 和 clang++ -std=c++17 main.cpp -o main；
- VS Code 的 C/C++ 扩展、IntelliSense、tasks.json 和断点调试；
- 终端当前目录、PATH 和工作区根目录。

### 练习产出

创建 hello.cpp，让它输出姓名、系统和当前学习阶段。分别在终端和 VS Code 中编译运行，并设置一个断点观察 main 函数。

### 完成标准

遇到“找不到编译器”或“IntelliSense 报错”时，能够先判断是工具链、PATH、编译任务还是编辑器配置的问题。

## 3. 阶段 1：基础语法和控制流程

### 学习目标

能够读懂一个简单的 C++ 程序，并使用变量、运算符、条件和循环完成小型计算。

### 核心内容

- include、main、语句、花括号和分号；
- int、long long、double、char、bool 和 string；
- 初始化、常量、算术运算、比较运算和逻辑运算；
- if/else、switch、for、while；
- 整数除法、类型转换和运算符优先级；
- cin、cout 和换行。

### 练习产出

完成成绩等级判断、温度转换、乘法表、数字求和和猜数字等练习。每道题都先写输入、处理、输出，再写代码。

### 完成标准

能把题目拆成变量、判断和循环；能解释为什么 5 / 2 是整数除法，以及怎样得到小数结果。

## 4. 阶段 2：函数、参数、返回值和作用域

### 学习目标

把过长的 main 拆成职责清楚的函数，并理解变量在哪里创建、在哪里可见、什么时候失效。

### 核心内容

- 函数声明、定义、参数和返回值；
- 值传递、引用传递的初步区别；
- 局部变量、全局变量、块作用域和变量遮蔽；
- 头文件和源文件的基本分工；
- const 参数和只读意图；
- 函数重载的使用边界。

### 练习产出

把“学习进度统计”拆成读取输入、计算平均值、判断等级和打印报告四个函数，再把函数声明放进头文件。

### 完成标准

能够回答变量在哪里定义、函数修改了谁、返回值是否需要复制，并能避免用全局变量传递所有状态。

## 5. 阶段 3：数组、字符串、指针和引用

### 学习目标

建立对象、地址、连续内存和生命周期的基本模型，理解为什么 C++ 既提供指针，也提供更安全的容器和字符串类型。

### 核心内容

- C 风格数组和下标；
- std::array、std::vector 和动态增长；
- C 风格字符串与 std::string；
- 地址运算符、解引用、空指针和指针移动；
- 引用、const 引用和函数参数；
- 栈、堆、对象生命周期和悬空指针风险。

### 练习产出

实现成绩列表：读取若干成绩，计算最大值、最小值和平均值；再分别用数组、vector 和函数参数重写一次。

### 完成标准

能够解释 vector 为什么比手写动态数组更适合初学阶段，知道什么时候传值、什么时候传 const&，并能识别越界和悬空引用。

## 6. 阶段 4：结构体、类和面向对象

### 学习目标

把数据和操作组织成具有明确职责的类型，理解封装、构造、继承和多态的使用场景。

### 核心内容

- struct 和 class 的默认访问权限；
- 成员变量、成员函数和构造函数；
- public、private、protected；
- this、初始化列表和 const 成员函数；
- 组合优先于继承；
- 虚函数、抽象类和运行时多态；
- 拷贝、移动和对象所有权的初步认识。

### 练习产出

设计 Student、Course 和 Progress 三个类型，完成添加课程、记录分数和生成学习报告的功能。

### 完成标准

能够说明一个类的职责，避免把所有数据都公开；知道继承不是复用代码的唯一方式，并能解释虚析构函数为什么重要。

## 7. 阶段 5：STL 标准库

### 学习目标

熟练使用标准容器和算法，让程序优先复用经过验证的库，而不是重复手写链表、排序和查找。

### 核心内容

- vector、array、deque；
- string 和 string_view；
- map、unordered_map、set；
- 迭代器、范围 for 和迭代器失效；
- sort、find、count、accumulate；
- pair、tuple、optional；
- 比较器、哈希和容器选择。

### 练习产出

读取一组单词，统计频率并按次数排序；再实现待办事项列表，用 vector 存储，用 sort 和 find_if 完成筛选。

### 完成标准

拿到集合类问题时，能先考虑容器和算法的组合，能比较 map 与 unordered_map 的特点，并能查阅标准库接口。

## 8. 阶段 6：模板与现代 C++

### 学习目标

理解 C++ 如何在编译期复用类型和算法，并形成现代 C++ 的基本习惯：RAII、const、自动推导、移动语义和智能指针。

### 核心内容

- 函数模板和类模板；
- auto、范围 for、结构化绑定；
- lambda 表达式和捕获；
- nullptr、enum class 和 constexpr；
- RAII、unique_ptr、shared_ptr 和所有权；
- 左值、右值、移动构造和 move；
- C++17 的 if constexpr、optional、variant；
- C++20 的概念、范围和模块的基本认识。

### 练习产出

写一个泛型最大值函数和一个接受 lambda 的过滤函数，再用 unique_ptr 管理动态创建的对象，说明它的所有权归谁。

### 完成标准

能够解释为什么优先使用自动对象和 RAII，知道 shared_ptr 不是默认答案；看到 move 时，能够继续追问对象是否真的发生了移动。

## 9. 阶段 7：文件、流、错误处理和异常

### 学习目标

让程序处理真实输入，而不是只处理写在代码里的常量，同时建立错误要被发现、表达和处理的意识。

### 核心内容

- ifstream、ofstream 和文件路径；
- 文本文件读取、写入和逐行处理；
- stringstream 和格式解析；
- 返回错误、optional 与异常的区别；
- try、catch、throw；
- 文件资源和对象生命周期；
- 日志、错误信息和用户可理解的提示。

### 练习产出

实现命令行成绩文件分析器：从文本文件读取姓名和成绩，计算统计结果，并把报告写入另一个文件。

### 完成标准

文件不存在、格式错误和输出失败时，程序不会静默产生错误结果；能够说明哪些错误适合返回值，哪些错误可以使用异常。

## 10. 阶段 8：工程化、调试、测试和 CMake

### 学习目标

把能运行的单文件程序提升为结构清晰、可以重复构建和验证的多文件项目。

### 核心内容

- 头文件保护、命名空间和编译单元；
- 编译警告：-Wall、-Wextra；
- Debug/Release 的区别；
- Git 的提交、分支和忽略生成目录；
- 单元测试和可测试的函数边界；
- CMakeLists.txt、project、add_executable 和 target_link_libraries；
- cmake -B build、cmake --build build 和 out-of-source 构建；
- VS Code CMake Tools 和编译数据库。

### 练习产出

把成绩分析器拆成 main.cpp、report.cpp、report.h，用 CMake 构建，把构建目录放在 build/ 而不是源码目录。

### 完成标准

新电脑上只看 README 和 CMake 配置就能重新构建项目；能够从编译错误定位到具体目标、源文件或头文件。

## 11. 阶段 9：算法与刷题

### 学习目标

从“代码能通过”进一步提升到“知道为什么这样写、复杂度是多少、还能不能更好”。

### 核心内容

- 时间复杂度、空间复杂度和数量级；
- 前缀和、双指针、滑动窗口、二分查找；
- 栈、队列、哈希表、并查集；
- DFS、BFS、贪心、动态规划；
- 排序、搜索和常见图结构；
- 读题、建模、边界测试和复盘记录；
- C++ 输入输出速度、整数范围和数据类型选择。

### 练习产出

每周选择一个专题，完成 3—5 道难度接近的题目。记录暴力思路、优化思路、复杂度、错误样例和最终代码。

### 完成标准

能在写代码前说出数据结构和复杂度的大致方向，能用小样例验证边界，并能把一次错误转化为下一次的检查清单。

## 12. 阶段 10：项目实践

### 学习目标

把语言知识、标准库、工程化和问题分析组合成一个可展示、可维护、可继续扩展的项目。

### 项目梯度

1. 命令行计算器：练习输入、函数、错误处理和测试。
2. 待办事项工具：练习类、vector、文件持久化和命令行参数。
3. 文件索引器：练习目录遍历、字符串处理、哈希表和排序。
4. 多文件成绩管理系统：练习 CMake、模块拆分、测试和报告生成。
5. 算法可视化或网络小工具：基础扎实后再接触图形库、网络库或第三方依赖。

### 练习产出

每个项目至少保留 README、构建说明、源代码、测试样例和一份复盘。不要只提交最终代码，也记录一次遇到的问题和解决过程。

### 完成标准

别人拿到仓库后，可以按照 README 安装依赖、执行 CMake 构建、运行示例和测试；你自己也能解释项目中最重要的三个设计选择。

## 13. 不要急着学什么

- 不要还没理解作用域就沉迷复杂模板报错；
- 不要还没能写多文件程序就先研究大型框架；
- 不要把指针理解成必须到处手写 new 和 delete；
- 不要为了追求新标准，把每个 C++20/23 特性都塞进第一个项目；
- 不要只看刷题答案，不写自己的边界测试和复盘；
- 不要把“能在自己电脑上运行”当成完整的工程化。

先把每一阶段的基础动作做扎实，再让项目推动下一阶段学习。C++ 的难点很多，但路线可以很具体：先让程序运行，再让代码清楚，最后让项目能够长期维护。
