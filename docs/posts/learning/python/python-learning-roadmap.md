# Python 学习路线：从基础语法到 Django Web

Python 的语法看起来简洁，但真正能够写项目，还需要掌握数据结构、标准库、面向对象、异常处理、依赖管理、测试和工程化。学习顺序如果只停留在“看完一章再看下一章”，很容易记住许多名词，却不知道如何把它们组合起来。

这条路线把学习拆成连续的阶段。每一阶段都要求留下一个可以运行的结果：一段脚本、一组练习、一个命令行工具或一个小型 Web 功能。先把基础语法学扎实，再进入数据库和 Web；机器学习等方向留到 Python 工程习惯稳定之后。

## 1. 推荐顺序

先完成[环境配置文章](/posts/learning/python/python-environment-setup.html)和 [Day 1 基础语法](/posts/learning/python/python-day-1.html)，然后按阶段推进：

| 阶段 | 重点 | 阶段产出 |
| --- | --- | --- |
| 0 | Python、终端、PyCharm、pip、.venv | 能运行脚本并使用正确解释器 |
| 1 | 基础语法与控制流 | 能独立完成小型计算程序 |
| 2 | 内置数据结构与函数 | 能处理一组数据并拆分逻辑 |
| 3 | 模块与标准库 | 能使用标准库解决文件、时间和日志问题 |
| 4 | 面向对象 | 能设计职责清楚的小型对象模型 |
| 5 | 文件与异常 | 能处理真实输入并给出可理解的错误信息 |
| 6 | 包与虚拟环境 | 能为项目管理依赖并保持环境可复现 |
| 7 | 数据库 | 能使用 SQLite 和 SQL 保存、查询、修改数据 |
| 8 | 网络请求 | 能调用 JSON API 并处理超时、错误和认证 |
| 9 | 测试 | 能为函数和接口编写稳定的自动化检查 |
| 10 | 工程化 | 能组织项目、配置工具、记录日志并持续集成 |
| 11 | Django Web 主线 | 能完成一个有数据模型和用户功能的 Web 项目 |
| 12 | Flask/FastAPI 拓展 | 能按场景选择轻量 Web 或 API 框架 |
| 13 | 后续方向 | 再进入自动化、数据分析、异步或机器学习 |

不要把表格当成一次性课程表。完成一个阶段的标志不是看完文字，而是能够解释核心概念、修改示例代码，并从空目录重新运行自己的练习。

## 2. 阶段 0：环境与基本工具

### 学习目标

理解 Python 解释器、脚本、终端、PyCharm、pip 和虚拟环境之间的关系，解决“代码明明安装了包却找不到”的第一类问题。

### 核心内容

- Windows Python Install Manager、python、py、py list；
- macOS python.org 安装器、Homebrew 和 Apple 系统 Python 的边界；
- PowerShell、Terminal、当前工作目录和 PATH；
- python -m pip、python -m venv .venv 和依赖隔离；
- PyCharm 项目解释器、运行配置和断点调试；
- .gitignore、项目目录和基础 Git 操作。

### 练习产出

创建一个 hello.py，打印 Python 版本、解释器路径和当前项目名称。在 PyCharm 和终端中分别运行，并设置断点。

### 完成标准

能够说明 PyCharm 和 Python 的区别；能够用 sys.executable 判断当前解释器；遇到命令找不到时，知道从 PATH、解释器和虚拟环境三个方向排查。

## 3. 阶段 1：Python 基础语法

### 学习目标

建立扎实的语法基础，能够把自然语言问题拆成变量、表达式、条件和循环。

### 核心内容

- 注释、缩进、变量和动态类型；
- int、float、bool、str、None；
- print、input、类型转换和 f-string；
- 算术、比较、逻辑、成员和身份运算符；
- if/elif/else、for、while、range、break、continue；
- 字符串索引、切片、常用方法和格式化。

### 练习产出

完成温度转换、成绩等级、猜数字、乘法表、密码强度初筛和学习进度记录器。每道题先写输入、处理和输出，再补充边界情况。

### 完成标准

能够独立解释 input 为什么需要类型转换，知道 range 的边界规则，能够写出没有死循环和明显缩进错误的小程序。

## 4. 阶段 2：内置数据结构与函数

### 学习目标

学会组织一组数据，并使用函数把长脚本拆成可复用、可测试的逻辑。

### 核心内容

- list、tuple、dict、set 的特点和选择；
- 索引、切片、遍历、解包和可变性；
- 字典的键、值、get 和嵌套结构；
- 列表、字典、集合推导式；
- def、参数、返回值、默认参数和关键字参数；
- 局部变量、作用域、递归初识和文档字符串；
- 可迭代对象、迭代器和生成器的直觉。

### 练习产出

实现一个命令行待办事项工具，用列表保存任务、用字典保存状态，使用函数完成新增、完成、删除和统计。

### 完成标准

拿到数据处理题时能够选择合适容器，能把重复逻辑提取为函数，能说明函数修改的是原对象还是返回了新对象。

## 5. 阶段 3：模块与标准库

### 学习目标

停止把所有代码写进一个文件，学会查阅标准库文档，并优先使用 Python 自带的成熟工具。

### 核心内容

- import、模块搜索路径、包和 name-main 入口；
- pathlib 处理路径和目录；
- datetime 处理日期与时间；
- json 读写结构化数据；
- re 处理有明确规则的文本匹配；
- collections 中的 Counter、defaultdict、deque；
- itertools 组合迭代器；
- logging 记录运行过程和错误；
- argparse 为脚本增加命令行参数。

### 练习产出

实现一个 Markdown 文件统计工具：遍历目录，统计文件数量、字数和修改时间，将结果输出为 JSON，并用 logging 记录异常。

### 完成标准

能够从模块中导入自己写的函数，能区分相对路径和当前工作目录，知道什么时候使用标准库而不是先寻找第三方包。

## 6. 阶段 4：面向对象

### 学习目标

把数据和相关行为组织为职责清楚的类型，为数据库模型、Django 视图和较大型项目建立基础。

### 核心内容

- 类、实例、属性和方法；
- init、实例变量和类变量；
- self、属性访问和封装；
- 继承、组合和多态；
- str、repr、比较方法等特殊方法；
- property、抽象基类和协议思维；
- dataclass、类型标注和依赖注入的初步认识。

### 练习产出

把阶段 2 的待办事项工具改造成 Task、TaskList 和 Report 三个类，让每个类承担清晰职责。

### 完成标准

能够判断一个问题是否真的需要类，优先使用组合而不是堆叠继承；能解释对象状态由谁维护、方法修改了什么以及如何测试。

## 7. 阶段 5：文件、异常与错误处理

### 学习目标

让程序能够处理真实文件和不理想的输入，并在出错时给使用者明确的反馈。

### 核心内容

- pathlib.Path 和跨平台路径；
- open、with、文本编码和换行；
- CSV、JSON 和简单配置文件；
- try/except/else/finally；
- 常见内置异常、自定义异常和异常链；
- 返回错误、None、异常和日志的边界；
- 输入验证、重试和失败后的清理。

### 练习产出

实现成绩文件分析器：读取 CSV，跳过或报告格式错误的行，计算统计结果，把报告写到 JSON，并保存运行日志。

### 完成标准

文件不存在、编码错误、格式错误和输出失败时，程序不会静默生成错误结果；能够避免用裸 except 吞掉所有异常。

## 8. 阶段 6：包、依赖与虚拟环境

### 学习目标

理解“模块、包、项目和可安装发行版”的区别，让项目可以在另一台电脑上重建。

### 核心内容

- 包目录、init 文件和导入边界；
- pip、PyPI、版本约束和依赖树；
- venv、.venv、激活与解释器路径；
- requirements.txt 的导出和安装；
- pyproject.toml、构建后端和现代包元数据；
- 可编辑安装、命令行入口和发布包的基本概念；
- lock 文件、环境变量和敏感配置。

### 练习产出

把文件统计工具整理成一个包，加入 pyproject.toml 和 README，创建新虚拟环境后完成安装、运行和卸载。

### 完成标准

能从空目录创建 .venv 并安装项目，能说清楚依赖描述文件与虚拟环境的区别，不把 .venv 或密钥提交到 Git。

## 9. 阶段 7：数据库

### 学习目标

掌握 SQL 和持久化的基本思维，为 Django ORM 和真实 Web 项目做好准备。

### 核心内容

- 表、行、列、主键、外键和索引；
- SELECT、INSERT、UPDATE、DELETE、JOIN 和聚合；
- SQLite 文件数据库与客户端工具；
- Python DB-API、连接、游标和参数化查询；
- 事务、提交、回滚和并发初识；
- ORM 的优点、限制和 N+1 问题。

### 练习产出

把待办事项工具从内存列表迁移到 SQLite，支持任务新增、完成、筛选和统计，并为数据库操作写函数测试。

### 完成标准

能够写出参数化 SQL，知道为什么不能把用户输入直接拼进 SQL 字符串，能解释事务何时提交和如何回滚。

## 10. 阶段 8：网络请求与 HTTP

### 学习目标

理解浏览器、服务器、HTTP 和 JSON API 的基本协作方式，能够安全地调用一个外部接口。

### 核心内容

- URL、HTTP 方法、状态码、请求头和响应体；
- requests 的 GET/POST、参数、JSON 和超时；
- 状态码检查、异常、重试和退避；
- API key、Bearer Token 和环境变量；
- 分页、限流、缓存和幂等性；
- 同步请求与异步请求的适用边界；
- 处理不可信输入和响应数据。

### 练习产出

编写一个 API 查询命令：从环境变量读取密钥，调用 JSON 接口，处理超时和非 2xx 状态码，把结果保存到本地文件。

### 完成标准

不会把密钥写进源码；请求设置明确超时；能区分网络失败、服务端错误、客户端错误和业务数据为空。

## 11. 阶段 9：测试

### 学习目标

让代码可以被重复验证，不再依赖“手动点几下看起来没问题”。

### 核心内容

- unittest 的 TestCase、断言和测试发现；
- pytest 的测试函数、fixture、参数化和标记；
- 单元测试、集成测试和端到端测试；
- mock、patch 和外部服务隔离；
- 临时目录、测试数据库和测试数据；
- 覆盖率的意义和边界；
- 先设计可测试的函数边界。

### 练习产出

为成绩分析器和 API 查询命令补充测试：覆盖正常输入、空文件、格式错误、超时和服务端错误。

### 完成标准

能够用一条命令运行测试，失败时能定位到具体行为；知道 mock 不是越多越好，关键业务逻辑应尽量使用真实、简单的数据测试。

## 12. 阶段 10：工程化

### 学习目标

把个人脚本提升为别人可以阅读、安装、运行和维护的项目。

### 核心内容

- Git 提交、分支、代码审查和 .gitignore；
- PEP 8、格式化、lint 和 import 排序；
- ruff、black 等工具的职责边界；
- 类型标注、mypy/pyright 的基本思路；
- pyproject.toml 集中管理项目工具；
- 配置、环境变量、日志和敏感信息；
- README、变更记录、语义化版本；
- GitHub Actions、测试、构建和基础部署。

### 练习产出

把前面的工具整理成一个 GitHub 项目：有 README、安装步骤、命令行入口、测试、格式化/lint 检查和 CI 工作流。

### 完成标准

新电脑上只看 README 就能创建环境并运行项目；提交前能自动执行格式检查、lint 和测试；日志中不泄露密钥。

## 13. 阶段 11：Django Web 主线

### 学习目标

使用 Django 的完整项目结构完成一个有数据、有用户和有测试的 Web 应用。Django 版本和支持的 Python 版本应以 Django 官方下载页与当前文档为准；当前资料显示 Django 6.1 系列已发布，但项目实践不要脱离官方支持矩阵硬锁版本。

### 推荐顺序

1. HTTP、HTML、浏览器与服务器的基本关系；
2. django-admin startproject、项目和应用的区别；
3. URLconf、视图、请求、响应和模板；
4. 模型、迁移、SQLite、查询集和 Django ORM；
5. Admin、自定义表单、校验和用户认证；
6. 静态文件、媒体文件、分页和消息；
7. 测试客户端、视图测试、模型测试和权限测试；
8. 配置拆分、生产数据库、静态资源、日志和部署。

### 练习产出

完成一个学习记录网站：用户可以登录，创建学习主题，记录每日进度，在后台管理数据，在页面上查看自己的学习时间和阶段总结。

### 完成标准

能够从空目录启动 Django 项目，说明 URL、视图、模板、模型和表单之间的数据流；关键功能有测试；部署时不会把 SECRET_KEY 和调试模式留在生产配置中。

## 14. 阶段 12：Flask 与 FastAPI 拓展

Django 适合需要完整约定、ORM、Admin、认证和后台能力的应用。学会 Django 主线后，再用两个小项目理解不同框架的取舍。

### Flask

Flask 更轻量，路由、请求处理、模板和扩展组合得更自由。它适合小型服务、原型、需要自定义结构的项目，也适合用来理解 Web 框架最小核心。

练习可以是一个只有几条路由的 JSON API，再接入 SQLite 和测试。参考 [Flask 官方文档](https://flask.palletsprojects.com/)。

### FastAPI

FastAPI 借助类型标注处理请求校验，并自动生成 API 文档，适合 API 服务和前后端分离项目。学习时重点理解依赖注入、Pydantic 数据模型、异步路由和 OpenAPI，而不是只记装饰器写法。

练习可以是一个带分页、校验、错误响应和测试的学习记录 API。参考 [FastAPI 官方文档](https://fastapi.tiangolo.com/)。

### 选择建议

~~~text
完整后台与约定优先       → Django
轻量服务与自由组合       → Flask
类型驱动的现代 API       → FastAPI
~~~

三者不是必须全部深入。根据项目目标选择一个主框架，再理解另外两个的设计差异即可。

## 15. 阶段 13：后续方向

完成基础路线和至少一个完整项目后，可以根据兴趣选择：

- 自动化脚本、命令行工具和定时任务；
- 异步编程、事件循环和高并发服务；
- 数据分析、NumPy、pandas 和可视化；
- 爬虫、数据清洗和任务队列；
- 机器学习、模型训练、评估和部署。

机器学习不是 Python 入门的下一章。进入机器学习前，最好先掌握函数、容器、面向对象、虚拟环境、测试和 Git，再补齐 NumPy、pandas、线性代数和概率统计。这样学到模型时，注意力可以放在数据和算法，而不是被环境或基础语法反复打断。

## 16. 推荐的学习节奏

每个阶段可以按下面的循环推进：

~~~text
理解概念 → 跟着示例运行 → 不看答案重写 → 修改一个需求 → 记录错误 → 总结完成标准
~~~

建议每周至少留下：

- 一篇学习笔记，写清楚自己真正理解了什么；
- 一组小练习，包含正常输入和边界输入；
- 一次代码整理，把重复逻辑提炼成函数或模块；
- 一次回顾，记录仍然模糊的问题和下一步行动。

路线不是一次性承诺。可以先完成阶段 0–2，再根据时间安排标准库和工程化；进入 Django 前，确保自己已经能独立写出不依赖框架的 Python 小程序。
