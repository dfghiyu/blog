# Python 学习

这里记录 Python 从基础语法到工程实践的学习过程。先把 Python、PyCharm 和虚拟环境配置好，再通过 Day 1 建立语法基础，随后逐步学习标准库、数据库、网络请求、测试、工程化和 Django Web。

推荐顺序是：先阅读环境配置文章，再完成 Day 1；之后按照路线总览中的阶段推进。每个阶段都留下一个能运行的小程序或小项目，机器学习等方向等 Python 基础和工程习惯稳定后再展开。
